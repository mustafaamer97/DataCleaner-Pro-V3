# 🚀 DataCleaner Pro V3 — Installation Guide

Welcome to DataCleaner Pro V3.

This guide explains how to install and run the application locally.

---

## 📋 Requirements

Before installing DataCleaner Pro, make sure you have:

- Python 3.10 or newer
- Internet connection for the initial installation
- Windows, macOS, or Linux
- At least 500 MB of available disk space

---
